# 🚀Pomodoro Planner - Приложение для концентрации внимания на учёбе, хобби или каком-либо другом занятии.
Pomodoro Planner помогает сосредоточиться на учёбе, работе или хобби, используя технику Помодоро, планирование и трекинг прогресса.

# 🔥 Основные функции
- ✅ Таймер Помодоро – стандартные 25/5 минут или гибкие настройки
- ✅ Планировщик задач – календарь для расписания и целей
- ✅ Свободный таймер – для любых задач без ограничений
- ✅ Статистика – трекинг времени и анализ продуктивности
